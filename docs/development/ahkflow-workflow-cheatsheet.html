AHKFlow workflow — eleven stages

Exit condition, then where success goes and where failure goes. Canonical text: workflow.md. Full tree with all five edges: workflow.html.

Stage Exit condition Success Failure
0 Intake Item filed with the script, summary written, Difficulty set 1-pickup stay
1 Pickup Location chosen by Difficulty, base confirmed and stated, PR route in place 2-design/3-plan/4-execute stay
2 Design Spec committed, terms and ADRs written, plain summary confirmed 3-plan stay
3 Plan Plan committed, grilled, fabrication-checked 4-execute stay
4 Execute All planned work committed, tracking current, stage push done 5-simplify stay
5 Simplify Simplification applied or verdict 'nothing to simplify' stated 6-verify stay
6 Verify Verification artifact green, gate green, verdict stated 7-document 4-execute
7 Document Docs updated or verdict 'nothing to document' stated 8-review stay
8 Review Review received, all threads resolved, gate re-green 9-ship 4-execute
9 Ship Records closed, PR ready, CI green, merged 10-cleanup 6-verify
10 Cleanup Worktree gone, branch deleted, memory updated terminal stay

Targets: a stage id goes to that stage. 2-design/3-plan/4-execute is the Difficulty split. stay means remain here. terminal means no next stage. The other three edges — blocked, not applicable, resume — are in workflow.md and workflow.html.
