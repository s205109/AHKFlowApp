AHKFlow artifact design system

One token set and one page skeleton for every AHKFlow document page. This page renders each element, so it is its own preview. Copy the tokens; do not invent new colours.

Action

Do not import Inter from Google Fonts. The Artifact content security policy blocks every external request, so the import fails silently and the page falls back to the system stack anyway. Ship the system stack, or embed the font as a data URI.

Summary

The spec lists two secondary text values. --text-secondary is the darker one. --text-secondary-alt is the lighter one. The amber callout background is a range, so it is a gradient from --summary-bg to --summary-bg-end.

Copyable page skeleton

Paste this into a blank file and it renders. It is self-contained: no external stylesheet, no external font, no script. 

<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Page title</title>
<style>
  :root {
    --font-stack: Inter, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
    --ground: #f8fafc;
    --card-bg: #ffffff;
    --card-border: #e2e8f0;
    --card-radius: 8px;
    --text-heading: #0f172a;
    --text-body: #334155;
    --text-secondary: #475569;
    --text-secondary-alt: #64748b;
    --text-muted: #94a3b8;
    --win-bg: #f0fdf4;      --win-border: #bbf7d0;      --win-text: #166534;
    --friction-bg: #fef2f2; --friction-border: #fca5a5; --friction-text: #991b1b;
    --summary-bg: #fef3c7;  --summary-bg-end: #fde68a;
    --summary-border: #f59e0b; --summary-text: #92400e;
    --action-bg: #eff6ff;   --action-border: #bfdbfe;   --action-text: #1e40af;
  }

  *, *::before, *::after { box-sizing: border-box; }
  body { margin: 0; }

  body {
    font-family: var(--font-stack);
    background: var(--ground);
    color: var(--text-body);
    line-height: 1.6;
    padding: 32px 20px 64px;
  }
  main { max-width: 860px; margin: 0 auto; }
  h1, h2, h3 { color: var(--text-heading); line-height: 1.25; margin: 0 0 12px; }

  .card {
    background: var(--card-bg);
    border: 1px solid var(--card-border);
    border-radius: var(--card-radius);
    padding: 20px 22px;
    margin: 16px 0;
  }

  @media print {
    @page { size: A4; margin: 14mm; }
    body { background: #ffffff; padding: 0; font-size: 11pt; }
    .card { break-inside: avoid; }
  }
</style>
</head>
<body>
<main>
  <h1>Page title</h1>
  <div class="card">
    <p>Card content.</p>
  </div>
</main>
</body>
</html>

Rules for every page built from this set

  • Self-contained. Zero external requests: no CDN, no web font, no remote image.
  • Colour is never the only signal. Every state carries text, a label, or a shape.
  • Every interactive element is reachable by keyboard, and its focus ring is visible.
  • An A4 print stylesheet is part of the page, not an afterthought.
  • Wide content scrolls inside its own container. The page body never scrolls sideways.

Token source: the wave-1 development process design, section 9 (private plans repo). First consumer: workflow.html.
